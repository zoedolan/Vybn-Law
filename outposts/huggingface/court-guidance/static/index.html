Court Guidance · a practical beta for courts adopting AI

How do we design systems that care at least as much as we do about getting things right?

The method: imagine the end state — a court’s own system — then work backward. Four layers, in order. Each opens into what it looks like in practice.

1 — raw material

The court already owns the beginning: its forms, guides, rules, and self-help pages.

2 — rules / guidelines

Statewide rules set the floor; each court writes its own corollaries — one requirement, one exact source, one owner.

3 — ethics / values

Lawyers answer to conduct rules; judges, to canons. The court’s AI answers to a public code of its own.

4 — self / own system

The end state, imagined first: the court’s own assistant, on the court’s own materials, under the court’s control.

Then the cycle repeats: the system returns sharper material, clearer rules, stronger standards.

Raw material: the court’s own shelf

yourcourt.gov/self-help
  • form Notice of appeal — fillable, in the court’s languages
  • guide What happens at oral argument, in plain words
  • rule Statewide appellate rules and this court’s local rules
  • form Fee-waiver application
  • info Self-help center hours, locations, interpreters
  • info Calendars, opinions, clerk’s counters

Nothing here is new — every court already publishes some version of this shelf. Step one is assembling yours and checking every item against its source. A public library like Public Counsel’s appellate clinic resources shows the plain shape: organized around real tasks, nothing decorative.

In practice · a public code, posted and versioned

Ethics / values: canons for the court’s AI

  1. Answer from the court’s own materials — and show the source with every answer.
  2. Say when it does not know. Never invent a rule, a date, a citation, or a fact.
  3. Never decide. The person keeps authorship of their case; a human reviews what the system affects.
  4. Serve both sides of the counter alike — the public, the clerk’s office, and the bench.

Judges answer to canons of ethics; lawyers, to rules of professional conduct. A court’s AI should answer to a code just as public — posted where anyone can read it, versioned when it changes.
